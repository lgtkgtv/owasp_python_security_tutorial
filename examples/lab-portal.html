🐳 OWASP Docker Labs

Local index for the 24 runnable vulnerable/secure lab pairs.

Make sure the containers are running first: cd examples && docker compose up -d (or start one module's own folder if you only want that pair). Clicking a link opens that lab's root endpoint in a new tab - the JSON response includes a "try" hint for the first request to make.
Everything here is deliberately vulnerable-by-design. Local use only - never expose these ports publicly.
